# افزونه‌های پیشنهادی (اختیاری)

قالب و افزونه اختصاصی برای امکانات اصلی به افزونه جانبی اجباری وابسته نیستند. موارد زیر برای محیط واقعی قابل استفاده‌اند؛ هر کدام را فقط پس از بررسی سازگاری نسخه PHP/وردپرس و تست staging نصب کنید.

| نیاز | پیشنهاد | نکته |
|---|---|---|
| سئو | Rank Math SEO یا Yoast SEO | یکی را انتخاب کنید، هر دو را هم‌زمان نصب نکنید. قالب متا description پایه دارد و در صورت فعال بودن این افزونه‌ها متای تکراری تولید نمی‌کند. |
| امنیت و فایروال | Wordfence Security یا Solid Security | یکی را انتخاب کنید؛ محدودسازی ورود، اسکن و اعلان‌ها را تنظیم کنید. جایگزین به‌روزرسانی و بکاپ نیست. |
| کش و سرعت | LiteSpeed Cache (روی LiteSpeed) یا WP Rocket | با توجه به وب‌سرور فقط یک راهکار کش اصلی فعال کنید. REST API، ورود OTP و فرم آپلود را از کش صفحه مستثنا کنید. |
| بکاپ | UpdraftPlus یا بکاپ سطح هاست | بکاپ دیتابیس و فایل‌های private مقاله را هم دربر بگیرد و بازیابی را آزمایش کنید. |
| SMTP | لازم نیست | ورود و اعلان‌های این سامانه پیامکی‌اند و فیلد ایمیل ندارد؛ افزونه SMTP برای جریان اصلی مورد نیاز نیست. |

درگاه پرداخت و ثبت‌نام پولی عمداً وارد پروژه نشده است. برای فایل‌های مقاله، اسکن ضدبدافزار سمت سرور (مانند ClamAV در سطح هاست) توصیه می‌شود. قبل از نصب هر افزونه، از سایت نسخه پشتیبان تهیه کنید.

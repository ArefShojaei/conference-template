# راه‌اندازی روی هاست و دامنه

این راهنما برای نصب تازه‌ی سایت است. قبل از جایگزین کردن سایت فعال، از فایل‌ها و دیتابیس بکاپ کامل بگیر.

## ۱) پیش‌نیازها
- WordPress نسخه 6.2 یا بالاتر
- PHP 8.1 یا بالاتر (ترجیحاً 8.2) و افزونه‌های PHP معمول وردپرس
- MySQL 8.0 یا MariaDB 10.5 یا بالاتر
- HTTPS فعال روی دامنه
- برای اعتبارسنجی DOCX: افزونه PHP یعنی `ZipArchive`
- `upload_max_filesize` و `post_max_size` حداقل 24M
- فضای ذخیره‌سازی خصوصی خارج از مسیر قابل دسترسی مستقیم وب برای فایل مقالات

## ۲) نصب قالب و افزونه
1. فایل `conference-1405-theme.zip` را از بخش فایل‌های خروجی GitHub Actions دریافت کن و از نمایش ← پوسته‌ها ← افزودن پوسته ← بارگذاری پوسته نصب کن.
2. فایل `conference-core-plugin.zip` را از افزونه‌ها ← افزودن افزونه ← بارگذاری افزونه نصب کن.
3. افزونه Conference Core را فعال و سپس قالب Conference 1405 را فعال کن.
4. از تنظیمات ← پیوندهای یکتا، ساختار دلخواه را انتخاب و یک بار ذخیره کن.
5. برگه‌های ورود، ثبت‌نام، داشبورد، ارسال مقاله، برنامه، سخنرانان، تیم، اخبار، تماس و راهنمای نویسندگان را بررسی کن. افزونه برگه‌های لازم را در فعال‌سازی ایجاد می‌کند.

## ۳) ورود محتوای نمونه
1. از دیتابیس مقصد بکاپ بگیر.
2. در `wp-config.php` مقدار `$table_prefix` را پیدا کن.
3. در فایل `conference-demo.sql` تمام `wp_`ها را با پیشوند واقعی جایگزین کن.
4. فایل را در دیتابیس همان نصب وردپرس از طریق phpMyAdmin وارد کن.
5. جزئیات و محدودیت‌ها در `demo-content/SQL-IMPORT.md` آمده است.

## ۴) پیکربندی ورود پیامکی
- کلید Kavenegar را فقط در `wp-config.php` و به‌صورت ثابت سمت سرور تعریف کن:
  `define('CONFERENCE_KAVENEGAR_API_KEY', 'کلید-خصوصی');`
- نام قالب‌های VerifyLookup تأییدشده برای OTP، رسید مقاله، نتیجه داوری و ثبت‌نام را در سامانه همایش ← تنظیمات پیامک وارد کن.
- کلید را در Git، فایل‌های قابل دانلود عمومی، HTML یا JavaScript قرار نده.
- قبل از استفاده عمومی، ارسال و دریافت پیامک را با یک شماره واقعی و قالب تأییدشده آزمایش کن.

## ۵) امن‌سازی فایل مقاله
- پوشه `wp-content/uploads/conference-private` نباید از وب قابل دسترسی باشد.
- برای Nginx در server block:
  ```nginx
  location ^~ /wp-content/uploads/conference-private/ {
      deny all;
      return 403;
  }
  ```
- برای Apache افزونه از قانون `.htaccess` استفاده می‌کند؛ دسترسی مستقیم را پس از نصب آزمایش کن.
- فایل‌ها فقط از مسیر کنترل‌شده و پس از بررسی نقش/مالکیت دانلود شوند.

## ۶) راه‌اندازی و تست پذیرش
- [ ] صفحه اصلی، اسلایدر، آمار، رنگ و اطلاعات تماس را از نمایش ← سفارشی‌سازی تنظیم کن.
- [ ] منوی اصلی و فوتر را از نمایش ← فهرست‌ها بساز.
- [ ] محتوای نمونه را بازبینی و اطلاعات ساختگی را قبل از انتشار عمومی اصلاح کن.
- [ ] یک حساب نویسنده واقعی با شماره موبایل تأییدشده بساز و نقش را از پیشخوان اختصاص بده.
- [ ] ورود/ثبت‌نام OTP، ارسال مقاله، دانلود مجاز و رد دانلود غیرمجاز را تست کن.
- [ ] یک داور بساز، مقاله را به او تخصیص بده و ثبت نتیجه و اعلان پیامکی را تست کن.
- [ ] ثبت‌نام شرکت‌کننده، پیام تماس، پیامک وضعیت و گواهی را تست کن.
- [ ] روی موبایل و دسکتاپ و مرورگرهای اصلی بررسی ظاهری انجام بده.
- [ ] بکاپ خودکار دیتابیس و فایل‌ها و مانیتورینگ خطا را فعال کن.

## مرز آماده‌بودن
این مخزن فایل‌های نصب قالب و افزونه و داده نمونه را فراهم می‌کند؛ اما نمی‌تواند به‌جای مالک هاست، کلید پیامک، تنظیمات DNS/SSL، نسخه PHP، قوانین Nginx/Apache، بکاپ و تست با حساب‌های واقعی را انجام دهد. تا وقتی چک‌لیست بالا روی هاست مقصد تکمیل نشده، سایت را آماده‌ی بهره‌برداری عمومی تلقی نکن.

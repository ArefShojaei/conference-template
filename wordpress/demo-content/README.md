# داده‌های نمونه وردپرس

دو روش برای پر کردن نصب وردپرس موجود است:

- **SQL کامل:** فایل [conference-demo.sql](conference-demo.sql) شامل نوشته‌ها، سخنرانان، جلسات، کمیته‌ها، برگه‌ها، فهرست اصلی، دسته‌بندی اخبار، تنظیمات سفارشی‌سازی و ابزارک‌هاست. راهنمای آن در [SQL-IMPORT.md](SQL-IMPORT.md) است.
- **WXR:** فایل [conference-demo.xml](conference-demo.xml) یک WordPress eXtended RSS برای انتقال محتوای متنی است؛ این فایل ابزارک‌ها و تنظیمات سفارشی‌سازی را منتقل نمی‌کند.

برای نصب تازه، مسیر پیشنهادی فعال‌سازی قالب و افزونه و سپس واردکردن SQL است. فایل SQL را با پیشوند واقعی دیتابیس هماهنگ کن و قبل از اجرا بکاپ بگیر. داده‌های نمونه را قبل از انتشار عمومی بازبینی کن.

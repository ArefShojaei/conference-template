# محتوای نمونه قابل درون‌ریزی

فایل `conference-demo.xml` را پس از فعال‌سازی قالب و افزونه از مسیر پیشخوان ← ابزارها ← درون‌ریزی ← WordPress وارد کنید.

این فایل WXR است (نه SQL dump) و ۱۴ محتوای نمونه دارد:
- ۳ نوشته اطلاع‌رسانی
- ۳ سخنران
- ۴ جلسه برنامه
- ۴ عضو کمیته

صفحات سیستمی مثل ورود، ثبت‌نام، داشبورد، ارسال مقاله، برنامه، سخنرانان و تماس را افزونه هنگام فعال‌سازی می‌سازد؛ در XML تکرار نشده‌اند. فایل، کاربر آزمایشی، شماره موبایل، فایل مقاله یا کلید API ایجاد نمی‌کند.

توضیحات کامل و مراحل import در `../README.md` آمده است. برای جلوگیری از داده تکراری، فایل را فقط یک بار و ترجیحاً روی نصب آزمایشی وارد کنید.

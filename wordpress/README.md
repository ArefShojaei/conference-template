# بسته وردپرس همایش ۱۴۰۵

## اجزا
- `theme/conference-1405/`: پوسته فارسی RTL با CSS و JS اصلی صفحات استاتیک.
- `conference-core/`: افزونه ثبت‌نام، ورود، ارسال مقاله، داوری و جداول اختصاصی.
- `demo/sample-data.sql`: داده‌های ساختگی برای تست نمایشی پس از فعال‌سازی افزونه.

## نصب آزمایشی
1. ابتدا یک نصب تازه WordPress و دیتابیس آزمایشی بسازید؛ روی سایت زنده نصب نکنید.
2. پوشه `wordpress/theme/conference-1405` را به `wp-content/themes/conference-1405` منتقل کنید.
3. پوشه `wordpress/conference-core` را به `wp-content/plugins/conference-core` منتقل کنید. نام پوشه باید با فایل اصلی افزونه همخوان باشد.
4. در پیشخوان، افزونه و سپس پوسته را فعال کنید.
5. تنظیمات > پیوندهای یکتا را باز و ذخیره کنید.
6. برای داده‌های نمونه، از دیتابیس پشتیبان بگیرید و فایل `demo/sample-data.sql` را فقط روی دیتابیس آزمایشی اجرا کنید. در SQL تمام پیشوندهای `wp_` را با پیشوند واقعی سایت جایگزین کنید.
7. وارد پنل مدیریت شوید و منوی «سامانه همایش» را بررسی کنید.

## مهم برای production
این branch هنوز release تاییدشده نیست. قبل از استفاده واقعی باید lint و تست end-to-end در staging اجرا شود، با نسخه PHP و MySQL هاست بررسی شود، ارسال ایمیل با SMTP واقعی آزمایش شود، فایل‌های مقاله خارج از web root نگهداری و دسترسی مستقیم آن‌ها در Apache/Nginx مسدود شود، نرخ درخواست فرم‌ها محدود شود، بکاپ/بازیابی آزمایش شود و خطاهای امنیتی/دسترسی نقش‌ها بازبینی شوند. داده‌های نمونه فقط برای نمایش هستند و مسیرهای فایل نمونه واقعی نیستند.

## قابلیت‌های خارج از دامنه فعلی
OAuth، پیامک، درگاه پرداخت، ثبت‌نام پولی، صدور خودکار PDF گواهی و استقرار روی دامنه/هاست واقعی در این نسخه پیاده‌سازی و تایید نشده‌اند. ثبت‌نام و ارسال مقاله برای نسخه فعلی رایگان در نظر گرفته شده است.

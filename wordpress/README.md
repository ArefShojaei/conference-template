# بسته وردپرس همایش ۱۴۰۵

این بسته یک پوسته فارسی RTL و افزونه امکانات همایش را کنار هم قرار می‌دهد. پوسته از نوشته‌ها، برگه‌ها، رسانه‌ها، فهرست‌های قابل ویرایش، ابزارک‌ها، دیدگاه‌های بومی وردپرس و اطلاعات قابل تنظیم همایش پشتیبانی می‌کند. افزونه، گردش‌کار پژوهشگر/مقاله/داوری و جدول‌های اختصاصی را اضافه می‌کند.

## بخش‌های قابل مدیریت از پیشخوان
- **نوشته‌ها و برگه‌ها:** محتوای عادی وب‌سایت و صفحات ثابت.
- **نمایش ← فهرست‌ها:** لینک‌های منوی اصلی و پابرگ.
- **نمایش ← سفارشی‌سازی ← اطلاعات همایش:** تاریخ و محل نمایش همایش.
- **رسانه‌ها:** تصویر شاخص و فایل‌های عمومی وب‌سایت.
- **دیدگاه‌ها:** مدیریت، تأیید، پاسخ و حذف نظرات وردپرس؛ دیدگاه‌ها باید در تنظیمات و صفحه مربوط فعال باشند.
- **کاربران:** ایجاد حساب، نقش‌های وردپرس و مدیریت حساب‌ها از پیشخوان.
- **همایش‌ها و سخنرانان:** نوع محتوای اختصاصی افزونه؛ عنوان، متن، خلاصه و تصویر شاخص از ویرایشگر وردپرس مدیریت می‌شوند.
- **سامانه همایش:** مدیریت مقالات و داوران و تنظیمات اختصاصی افزونه.

## نصب روی محیط آزمایشی
1. یک نصب تازه وردپرس و دیتابیس آزمایشی بسازید.
2. پوشه wordpress/theme/conference-1405 را به wp-content/themes/conference-1405 منتقل کنید.
3. پوشه wordpress/conference-core را به wp-content/plugins/conference-core منتقل کنید.
4. افزونه را فعال کنید و سپس پوسته را فعال کنید.
5. از تنظیمات ← پیوندهای یکتا یک بار ذخیره کنید.
6. منوی اصلی و پابرگ را از پیشخوان بسازید و تخصیص دهید.
7. برای داده‌های نمایشی، از دیتابیس بکاپ بگیرید و wordpress/demo/sample-data.sql را فقط در دیتابیس آزمایشی اجرا کنید. پیشوند تمام جدول‌های wp_ را با پیشوند واقعی نصب جایگزین کنید.
8. برای نمایش دیدگاه‌ها، دیدگاه‌ها را در تنظیمات گفت‌وگو و صفحه/نوشته مربوط فعال کنید.

## نکته‌های دیتابیس
- جداول اختصاصی افزونه با فعال‌سازی افزونه و dbDelta() ساخته می‌شوند؛ SQL نمونه داده‌ها را وارد می‌کند و جایگزین نصب افزونه نیست.
- WordPress کاربران، نوشته‌ها، برگه‌ها، رسانه‌ها و دیدگاه‌ها را در جداول استاندارد خودش نگه می‌دارد.
- داده‌های SQL نمونه ساختگی‌اند؛ مسیر فایل مقاله‌ها placeholder است و فایل PDF واقعی ندارد. آن را روی سایت اصلی وارد نکنید.

## وضعیت آمادگی
این branch هنوز نسخه‌ی production تأییدشده نیست. بررسی خودکار نحو PHP به GitHub Actions اضافه شده، اما تا زمان اجرای موفق workflow و تست end-to-end روی staging نمی‌توان آن را release آماده اعلام کرد. قبل از production موارد زیر لازم‌اند:
- اجرای workflow و اصلاح هر خطای PHP؛
- تست ثبت‌نام، تأیید ایمیل، ورود، ارسال و دانلود امن مقاله، تخصیص داور، ذخیره نظر و تغییر وضعیت از ابتدا تا انتها؛
- بررسی دسترسی نقش‌ها و ذخیره‌سازی خصوصی فایل‌ها روی وب‌سرور واقعی؛
- تنظیم SMTP، بکاپ/بازیابی و تست روی نسخه PHP/MySQL هاست؛
- تست سازگاری قالب در موبایل و مرورگرهای اصلی.

OAuth، پیامک، درگاه پرداخت و ثبت‌نام پولی در این نسخه پیاده‌سازی نشده‌اند. ارسال مقاله و داوری بدون پرداخت طراحی شده‌اند.

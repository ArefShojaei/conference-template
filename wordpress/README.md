# بسته وردپرسی همایش فناوری و نوآوری ۱۴۰۵

این پوشه نسخه وردپرسی پروژه است. فایل‌های HTML ریشه مخزن مرجع طراحی و دارایی‌های رابط کاربری‌اند؛ فایل‌های CSS و JavaScript و دارایی‌های موجود در پوشه قالب وردپرس از همان سورس کپی شده‌اند. قالب و افزونه با هم نصب می‌شوند تا ظاهر و منطق سامانه از هم جدا بمانند.

## اجزای بسته

- `themes/conference-1405`: قالب فارسی RTL، هدر/فوتر، صفحه اصلی، صفحات نوشته/برگه/آرشیو، صفحات اختصاصی ورود و ثبت‌نام، سفارشی‌سازی، منوها و ابزارک‌ها.
- `plugins/conference-core`: احراز هویت OTP، نقش‌ها و دسترسی‌ها، فرم‌های همایش، ارسال/دانلود امن مقاله، ثبت‌نام شرکت‌کننده، گردش‌کار داوری، پیام‌ها، گواهی‌ها و صفحات مدیریتی.
- `demo-content/conference-demo.sql`: Seed کامل نمونه برای نوشته‌ها، سخنرانان، برنامه، کمیته‌ها، برگه‌ها، فهرست، ابزارک‌ها و تنظیمات سفارشی‌سازی.
- `demo-content/conference-demo.xml`: روش جایگزین WXR برای انتقال محتوا؛ این فایل ابزارک و تنظیمات سفارشی‌سازی را منتقل نمی‌کند.
- `INSTALLATION-CHECKLIST.md`: مراحل نصب و تست روی هاست و دامنه.

## صفحات و مسیرها

افزونه در زمان فعال‌سازی و نیز هنگام ارتقا، مسیرهای زیر را در صورت نبودن ایجاد می‌کند. بنابراین لازم نیست برگه‌ها را دستی بسازی یا برای هرکدام طراحی جدید انجام بدهی.

| گروه | مسیرها |
|---|---|
| عمومی | `/`, `/about/`, `/speakers/`, `/schedule/`, `/papers/`, `/team/`, `/news/`, `/posts/`, `/contact/`, `/faq/`, `/author-guidelines/` |
| ورود و ثبت‌نام | `/login/`, `/register/` |
| کاربر | `/dashboard/`, `/profile/`, `/my-papers/`, `/my-registration/`, `/event-registration/`, `/certificates/`, `/messages/`, `/submit-paper/` |
| داور | `/reviewer-dashboard/`, `/review-queue/`, `/review-paper/?paper_id=123`, `/my-reviews/` |
| مدیر | `/admin-dashboard/`, `/admin-users/`, `/admin-papers/`, `/admin-registrations/`, `/admin-reviews/`, `/admin-reviewers/`, `/admin-settings/`, `/admin-sms/`, `/admin-team/`, `/admin-posts/` |

صفحات ورود و ثبت‌نام از قالب اختصاصی و فرم OTP استفاده می‌کنند. پنل کاربر، داور و مدیر داده‌های واقعی وردپرس را می‌خوانند و بر اساس قابلیت‌های حساب محدود می‌شوند. صفحات مدیریت عمومی نیستند و فقط برای نقش دارای `manage_conference` یا مدیرکل وردپرس نمایش داده می‌شوند.

## نصب

1. WordPress را روی هاست نصب کن.
2. پوشه قالب را در `wp-content/themes/conference-1405` و افزونه را در `wp-content/plugins/conference-core` قرار بده؛ یا ZIPهای خروجی GitHub Actions را از پیشخوان نصب کن.
3. افزونه **Conference Core** را فعال کن، سپس قالب **Conference 1405** را فعال کن.
4. از تنظیمات ← پیوندهای یکتا یک بار ذخیره کن.
5. برگه‌ها، فهرست اصلی، ابزارک‌های پیش‌فرض و سفارشی‌سازی اولیه به‌صورت خودکار آماده می‌شوند.

## واردکردن دیتای نمونه SQL

فایل `demo-content/conference-demo.sql` شامل این موارد است:
- ۵ سخنران، ۱۲ نشست، ۴ عضو کمیته و ۴ نوشته خبری
- مسیرهای صفحات عمومی، احراز هویت، پنل کاربر، داور و مدیر
- فهرست اصلی و دسته‌بندی اخبار
- گزینه‌های `theme_mods_conference-1405` شامل عنوان/تاریخ/مکان، رنگ، اسلایدرها، متن بخش‌های صفحه اصلی، آمار، کارت‌های ویژگی و تاریخ‌های مهم
- سه ابزارک نمونه و اتصال آن‌ها به Sidebarهای فوتر و صفحه اصلی

روش ورود: ابتدا قالب و افزونه را فعال کن، از دیتابیس بکاپ بگیر، پیشوند تمام جدول‌های `wp_` در فایل SQL را با مقدار `$table_prefix` در `wp-config.php` جایگزین کن و سپس فایل را در دیتابیس همان نصب از طریق phpMyAdmin اجرا کن. راهنمای جزئیات در [SQL-IMPORT.md](demo-content/SQL-IMPORT.md) است. فایل SQL بکاپ کامل وردپرس نیست و کاربر، رمز، شماره موبایل، کلید API یا مقاله خصوصی نمی‌سازد.

## وظیفه قالب و افزونه

- **قالب:** نمایش و تجربه کاربری، RTL و واکنش‌گرایی، هدر و فوتر، صفحه اصلی، تمپلیت نوشته و برگه، اسلایدر، رنگ‌بندی، تنظیمات سفارشی‌سازی، منوها و ابزارک‌ها.
- **افزونه:** منطق برنامه؛ ورود و ثبت‌نام با شماره موبایل و OTP، ساخت حساب بدون ایمیل، تعیین نقش توسط مدیر، نقش داور/نویسنده/مدیر همایش، ارسال مقاله، تخصیص داور، ثبت نتیجه، ثبت‌نام حضور، اعلان پیامکی، صندوق تماس و گواهی‌ها.

منطق سامانه داخل افزونه است تا تغییر قالب در آینده داده‌ها و گردش‌کارهای همایش را از بین نبرد.

## احراز هویت و نقش‌ها

- ورود و ثبت‌نام فقط با شماره موبایل ایران و کد یک‌بارمصرف است.
- ثبت‌نام نام، نام خانوادگی، شماره و پذیرش قوانین می‌گیرد؛ فیلد ایمیل و انتخاب نقش توسط کاربر وجود ندارد.
- حساب جدید با نقش پایه نویسنده همایش ایجاد می‌شود؛ مدیر بعداً نقش و دسترسی مناسب را تعیین می‌کند.
- مدیران قدیمی می‌توانند شماره موبایل را در پروفایل کاربر ثبت کنند تا ورود OTP فعال شود.
- کد OTP به‌صورت hash ذخیره می‌شود، انقضای پنج‌دقیقه‌ای و سقف تلاش/درخواست دارد. ارسال واقعی نیازمند کلید و قالب VerifyLookup معتبر Kavenegar است.

## ارسال مقاله و امنیت فایل

- فرمت PDF، DOC و DOCX، حداکثر ۲۰ مگابایت.
- پسوند و امضای فایل بررسی می‌شود؛ DOCX با ZipArchive و ساختار داخلی ZIP بررسی می‌شود.
- فایل‌های جدید در پوشه خصوصی خارج از Document Root ذخیره می‌شوند. در صورت نیاز مسیر مطلق را با `CONFERENCE_PRIVATE_STORAGE_DIR` در `wp-config.php` تعیین کن؛ متغیر PHP یعنی `DOCUMENT_ROOT` باید در هاست قابل تشخیص باشد و در غیر این صورت افزونه آپلود را fail-closed متوقف می‌کند.
- دانلود فقط از endpoint احراز هویت‌شده و پس از بررسی مالکیت/تخصیص داور انجام می‌شود.
- برای DOCX باید `ZipArchive` فعال باشد. محدودیت `upload_max_filesize` و `post_max_size` را حداقل 24M قرار بده.

## تنظیم پیامک

در `wp-config.php` و خارج از Git:
```php
define('CONFERENCE_KAVENEGAR_API_KEY', 'YOUR_PRIVATE_API_KEY');
```
سپس قالب‌های VerifyLookup برای OTP، رسید مقاله، نتیجه داوری و ثبت‌نام را در سامانه همایش ← تنظیمات پیامک وارد کن. کلید API را در گفتگو یا فایل عمومی قرار نده.

## کش، SEO و پرفورمنس

- صفحات `login`, `register`, `dashboard`, صفحات پنل و REST API را از page cache خارج کن.
- برای صفحات عمومی از cache افزونه هاست استفاده کن؛ صفحات شخصی و پاسخ‌های REST نباید cache عمومی شوند.
- تصاویر شاخص فشرده و WebP، اندازه مناسب، lazy loading و CDN را در هاست فعال کن.
- فقط یک افزونه کش و یک افزونه SEO انتخاب کن؛ چند افزونه هم‌پوشان را هم‌زمان نصب نکن.
- سایت را با HTTPS و بکاپ منظم دیتابیس و فایل‌های خصوصی راه‌اندازی کن.

## تست الزامی پیش از انتشار

این مخزن بدون دسترسی به هاست، کلید پیامک و DNS نمی‌تواند نصب نهایی را روی دامنه تو آزمایش کند. قبل از انتشار عمومی باید OTP واقعی، ثبت‌نام، آپلود/دانلود مجاز و غیرمجاز، تخصیص داور، ثبت نتیجه، پیامک، فرم تماس، گواهی، فهرست‌ها، ابزارک‌ها و نمایش موبایل/دسکتاپ روی هاست مقصد تست شوند. چک‌لیست کامل در [INSTALLATION-CHECKLIST.md](INSTALLATION-CHECKLIST.md) قرار دارد.

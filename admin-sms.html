پنل پیامکی

مدیریت اطلاعات و گردش کار همایش از یک فضای یکپارچه.

دوره پاییز ۱۴۰۵
i

حالت پیش‌نمایش این صفحه رابط کاربری است؛ داده‌ها ذخیره یا به سرویس خارجی ارسال نمی‌شوند.

ارسال پیامک

پیش‌نمایش فرم ارسال اطلاع‌رسانی

برای ارسال واقعی، اتصال درگاه پیامکی، مدیریت رضایت/لغو عضویت، محدودیت نرخ و ثبت گزارش تحویل لازم است.

وضعیت سرویس

درگاه متصل نیست.

کلید API را هرگز در HTML یا JavaScript سمت مرورگر قرار ندهید؛ فقط در تنظیمات امن سرور نگهداری شود.

رویدادهای پیامکی خودکار

در نسخه عملیاتی، هر رویداد از طریق صف پیامک به شماره تأییدشده کاربر اطلاع‌رسانی می‌شود.

نیازمند اتصال سرویس
حساب و ثبت‌نام
  • کد تأیید ورود و ثبت‌نام (OTP)
  • تأیید ایجاد حساب و ثبت‌نام همایش
  • وضعیت پرداخت و رسید
مقاله و داوری
  • تأیید دریافت مقاله و کد رهگیری
  • تخصیص داور و یادآوری مهلت داوری
  • نتیجه داوری، اصلاحات، پذیرش یا رد
رویداد و حضور
  • یادآوری زمان نشست‌ها و کارگاه‌ها
  • تغییر برنامه و اطلاعیه‌های مهم
  • اطلاعات حضور و صدور گواهی
گزارش و کنترل
  • وضعیت صف، ارسال، تحویل و خطا
  • تلاش مجدد کنترل‌شده و گزارش هزینه
  • قالب پیامک و تاریخچه اعلان‌ها

پیامک‌های نتیجه داوری نباید حاوی جزئیات محرمانه باشند؛ پیام کوتاه وضعیت و لینک ورود به پنل امن ارسال شود. کلید API فقط در سرور نگهداری شود.

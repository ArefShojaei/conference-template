# قالب کامل وب‌سایت همایش و رویداد (فارسی / RTL)

قالب رابط کاربری HTML ایستا برای وب‌سایت همایش، کنفرانس و رویداد علمی. این مخزن در وضعیت فعلی **سامانه عملیاتی نیست**؛ فرم‌ها و ورود صرفاً نمایشی‌اند و داده‌ها در backend ذخیره نمی‌شوند.

- [گزارش ممیزی فنی](docs/AUDIT.md)
- [برنامه اصلاح و اجرا](docs/IMPLEMENTATION-PLAN.md)
- [پیش‌نمایش بازطراحی MVP](index.html) — اسلایدر صفحه اصلی، ورود/ثبت‌نام جدید و پنل مدیریت بازطراحی‌شده در شاخه `feature/mvp-visual-redesign`.

قابلیت‌های رابط کاربری:

- راست‌چین (RTL)
- فونت فارسی Vazirmatn
- طراحی مدرن و ریسپانسیو
- پنل کاربری، پنل داوری و پنل مدیریت
- صفحات ثبت‌نام، ارسال مقاله، داوری و ...

## نحوه استفاده

1. فایل‌ها را از حالت فشرده خارج کنید.
2. فایل `index.html` را در مرورگر باز کنید.
3. صفحه `login.html` فقط ورود نمایشی با `localStorage` دارد؛ انتخاب نقش، احراز هویت یا مجوز واقعی ایجاد نمی‌کند.
4. فرم‌ها ورودی‌ها را در مرورگر بررسی می‌کنند، اما اطلاعات را ارسال یا ذخیره نمی‌کنند.
5. فرم ارسال مقاله فایل را فقط در مرورگر بررسی می‌کند؛ فایلی روی سرور بارگذاری نمی‌شود.

## بازطراحی رابط MVP

شاخه `feature/mvp-visual-redesign` جهت بصری تازه‌ای با پالت سبز جنگلی/سبزآبی و طلایی، صفحه اصلی اسلایدری، صفحات ورود و ثبت‌نام بازطراحی‌شده و داشبورد مدیریت بازچینی‌شده دارد. این شاخه هنوز پیش‌نمایش ایستا است؛ داده‌ها نمونه‌اند و فرم‌ها به backend متصل نیستند.

## تبدیل به وردپرس

این قالب به صورت HTML خالص طراحی شده و ساختار تمیز و جداسازی CSS/JS دارد تا بتوانید:

- آن را به قالب وردپرس تبدیل کنید
- از آن به عنوان استاتیک در هاست استفاده کنید
- یا با فریم‌ورک‌هایی مثل Next.js / Nuxt ترکیب کنید

پیشنهاد برای وردپرس:
- هدر و فوتر را به `header.php` و `footer.php` تبدیل کنید
- صفحات پنل را با نقش‌های کاربری وردپرس و پلاگین‌هایی مثل Ultimate Member یا سفارشی‌سازی پیاده‌سازی کنید
- فرم‌ها را با Contact Form 7 یا Gravity Forms جایگزین کنید

## تکمیل صفحات در شاخه feature/complete-responsive-html-pages

صفحات تکمیلی رابط کاربری:
- عمومی: `team.html` (تیم و کمیته‌ها)، `posts.html` (اخبار و اطلاعیه‌ها)، `author-guidelines.html` (راهنمای نویسندگان)
- مدیریت: `admin-reviewers.html`، `admin-sms.html`، `admin-team.html`، `admin-posts.html`
- لایه‌های تکمیلی واکنش‌گرایی: `css/responsive-fixes.css` و قواعد مشترک افزوده‌شده به `css/style.css`

**محدودیت مهم:** صفحات جدید نیز مانند سایر فایل‌های HTML پیش‌نمایش رابط هستند. هیچ پیامکی ارسال نمی‌شود، داده‌ای ذخیره نمی‌شود و احراز هویت/مجوزدهی واقعی وجود ندارد. برای بهره‌برداری، باید API و منطق سمت سرور وردپرس، نقش‌ها و قابلیت‌ها، nonce/CSRF، اعتبارسنجی و پاک‌سازی ورودی، کنترل فایل و ثبت رویدادها پیاده‌سازی و آزمون شوند.

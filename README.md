# قالب کامل وب‌سایت همایش و رویداد (فارسی / RTL)

قالب HTML استاتیک کامل برای وب‌سایت همایش، کنفرانس و رویداد علمی با پشتیبانی کامل از:

- راست‌چین (RTL)
- فونت فارسی Vazirmatn
- طراحی مدرن و ریسپانسیو
- پنل کاربری، پنل داوری و پنل مدیریت
- صفحات ثبت‌نام، ارسال مقاله، داوری و ...

## ساختار صفحات

### صفحات عمومی
| فایل | توضیحات |
|------|---------|
| `index.html` | صفحه اصلی |
| `about.html` | درباره همایش |
| `speakers.html` | سخنرانان |
| `schedule.html` | برنامه زمانی (با تب) |
| `papers.html` | لیست مقالات پذیرفته‌شده |
| `register.html` | ثبت‌نام (با تعرفه‌ها) |
| `login.html` | ورود (با انتخاب نقش دمو) |
| `submit-paper.html` | ارسال مقاله |
| `contact.html` | تماس با ما |
| `faq.html` | سوالات متداول |

| فایل | توضیحات |
|------|---------|

| `profile.html` | پروفایل |
| `my-papers.html` | مقالات من |

### پنل داور
| فایل | توضیحات |
|------|---------|

### پنل مدیریت (ادمین)
| فایل | توضیحات |
|------|---------|
| `admin-dashboard.html` | داشبورد ادمین |
| `admin-users.html` | مدیریت کاربران |

## نحوه استفاده

1. فایل‌ها را از حالت فشرده خارج کنید.
2. فایل `index.html` را در مرورگر باز کنید.
3. برای تست پنل‌ها از صفحه **ورود** استفاده کنید و نقش مورد نظر (کاربر / داور / ادمین) را انتخاب کنید.

## تبدیل به وردپرس

این قالب به صورت HTML خالص طراحی شده و ساختار تمیز و جداسازی CSS/JS دارد تا بتوانید:

- آن را به قالب وردپرس تبدیل کنید
- از آن به عنوان استاتیک در هاست استفاده کنید
- یا با فریم‌ورک‌هایی مثل Next.js / Nuxt ترکیب کنید

پیشنهاد برای وردپرس:
- هدر و فوتر را به `header.php` و `footer.php` تبدیل کنید
- صفحات پنل را با نقش‌های کاربری وردپرس و پلاگین‌هایی مثل Ultimate Member یا سفارشی‌سازی پیاده‌سازی کنید
- فرم‌ها را با Contact Form 7 یا Gravity Forms جایگزین کنید

## تکنولوژی‌ها

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- JavaScript (Vanilla)
- فونت: Vazirmatn (Google Fonts)
- کاملاً ریسپانسیو

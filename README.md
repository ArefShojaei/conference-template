# قالب کامل وب‌سایت همایش و رویداد (فارسی / RTL)

فایل‌های HTML ریشه این مخزن، مرجع طراحی و پیش‌نمایش رابط کاربری همایش هستند و به‌تنهایی backend ندارند. نسخه وردپرسی پروژه در پوشه **[wordpress/](wordpress/README.md)** قرار دارد و شامل قالب، افزونه، صفحات سیستمی، ورود OTP، گردش‌کار مقاله و داده نمونه SQL است. عملیاتی‌شدن روی دامنه مقصد به نصب و پیکربندی هاست و تست سرویس‌های واقعی نیاز دارد.

- [گزارش ممیزی فنی](docs/AUDIT.md)
- [برنامه اصلاح و اجرا](docs/IMPLEMENTATION-PLAN.md)
- [پیش‌نمایش بازطراحی MVP](index.html) — اسلایدر صفحه اصلی، ورود/ثبت‌نام جدید و پنل مدیریت بازطراحی‌شده در شاخه `feature/mvp-visual-redesign`.

قابلیت‌های رابط کاربری:

- راست‌چین (RTL)
- فونت فارسی Vazirmatn
- طراحی مدرن و ریسپانسیو
- پنل کاربری، پنل داوری و پنل مدیریت
- صفحات ثبت‌نام، ارسال مقاله، داوری و ...

## نحوه استفاده

1. فایل‌ها را از حالت فشرده خارج کنید.
2. فایل `index.html` را در مرورگر باز کنید.
3. صفحه `login.html` و `register.html` فقط پیش‌نمایش جریان ورود/ثبت‌نام با شماره موبایل و OTP هستند؛ ارسال پیامک و احراز هویت واقعی نیازمند backend است. نقش‌ها باید فقط سمت سرور تعیین شوند.
4. ورود و ثبت‌نام در پیش‌نمایش، جریان کد یک‌بارمصرف را نشان می‌دهند اما پیامک واقعی ارسال نمی‌کنند؛ همه فرم‌ها صرفاً در مرورگر بررسی می‌شوند و اطلاعات ذخیره نمی‌شود.
5. فرم ارسال مقاله فایل را فقط در مرورگر بررسی می‌کند؛ فایلی روی سرور بارگذاری نمی‌شود.

## بازطراحی رابط MVP

شاخه `feature/mvp-visual-redesign` جهت بصری تازه‌ای با پالت سبز جنگلی/سبزآبی و طلایی، صفحه اصلی اسلایدری، صفحات ورود و ثبت‌نام بازطراحی‌شده و داشبورد مدیریت بازچینی‌شده دارد. این شاخه هنوز پیش‌نمایش ایستا است؛ داده‌ها نمونه‌اند و فرم‌ها به backend متصل نیستند.

## نسخه وردپرسی پروژه

نسخه قابل نصب وردپرس در پوشه [wordpress](wordpress/README.md) نگهداری می‌شود. این بسته شامل:
- قالب RTL با ظاهر سبز، صفحه اصلی، هدر/فوتر، تمپلیت برگه و نوشته، منوها، ابزارک‌ها و سفارشی‌سازی
- صفحات از پیش ساخته‌شده برای ورود، ثبت‌نام، داشبورد کاربر، پنل داور، پنل مدیر و تمام مسیرهای عمومی
- افزونه Conference Core برای OTP موبایل، نقش‌ها و دسترسی‌ها، ارسال امن مقاله، ثبت‌نام، داوری، اعلان‌ها و گواهی‌ها
- فایل [SQL نمونه کامل](wordpress/demo-content/conference-demo.sql) برای داده، برگه، نوشته، فهرست، ابزارک و تنظیمات قالب
- [چک‌لیست نصب روی هاست و دامنه](wordpress/INSTALLATION-CHECKLIST.md)

فایل‌های HTML ریشه به‌عنوان مرجع طراحی باقی مانده‌اند؛ برای نصب وردپرس از بسته داخل پوشه `wordpress/` استفاده کن و مراحل آن را در README همان پوشه دنبال کن.

## تکمیل صفحات در شاخه feature/complete-responsive-html-pages

صفحات تکمیلی رابط کاربری:
- عمومی: `team.html` (تیم و کمیته‌ها)، `posts.html` (اخبار و اطلاعیه‌ها)، `author-guidelines.html` (راهنمای نویسندگان)
- مدیریت: `admin-reviewers.html`، `admin-sms.html`، `admin-team.html`، `admin-posts.html`
- لایه‌های تکمیلی واکنش‌گرایی: `css/responsive-fixes.css` و قواعد مشترک افزوده‌شده به `css/style.css`

**محدودیت مهم:** صفحات جدید نیز مانند سایر فایل‌های HTML پیش‌نمایش رابط هستند. هیچ پیامکی ارسال نمی‌شود، داده‌ای ذخیره نمی‌شود و احراز هویت/مجوزدهی واقعی وجود ندارد. برای بهره‌برداری، باید API و منطق سمت سرور وردپرس، نقش‌ها و قابلیت‌ها، nonce/CSRF، اعتبارسنجی و پاک‌سازی ورودی، کنترل فایل و ثبت رویدادها پیاده‌سازی و آزمون شوند.


## بسته وردپرسی

قالب و افزونه عملیاتی اولیه در پوشه [wordpress](wordpress/README.md) قرار گرفته‌اند. برای نصب قالب `wordpress/themes/conference-1405` و افزونه `wordpress/plugins/conference-core` را به مسیرهای استاندارد وردپرس منتقل کنید. راهنمای نصب، تنظیم Kavenegar، امنیت فایل‌های مقاله و افزونه‌های پیشنهادی در همان پوشه است.

**توجه:** فایل‌های HTML ریشه همچنان پیش‌نمایش ایستا هستند؛ نسخه وردپرسی در پوشه جداگانه قرار دارد. پیامک واقعی پس از وارد کردن کلید و قالب‌های تأییدشده در هاست فعال می‌شود.
